# Документація інтерфейсів

Цей розділ містить документацію всіх інтерфейсів та типів системи.

## Модулі

### [Модулі](./modules.md)
- `BuildingsManager` — управління будівлями та їх станом
- `DroneManager` — управління дронами та їх характеристиками
- `ResourceManager` — управління ресурсами та їх балансами
- `UpgradesManager` — управління апгрейдами та їх рівнями

## Системи

### [Системи](./systems.md)
- `MapLogic` — головна логіка карти та генерація ресурсів
- `BonusSystem` — система бонусів та модифікаторів
- `RequirementsSystem` — система перевірки вимог
- `SceneLogic` — логіка 3D сцени
- `SaveLoadManager` — система збереження/завантаження

### [Система команд](./commands-system.md)
- `Command` — основний інтерфейс команди
- `CommandGroup` — визначення групи команд
- `ICommandSystem` — інтерфейс системи команд
- `ICommandQueue` — інтерфейс черги команд
- `CommandExecutor` — базовий клас виконавця команд

### [Додаткові системи](./additional-systems.md)
- `MapLogic` — головна логіка карти та генерація ресурсів
- `TerrainManager` — управління террейном з детермінованою генерацією
- `PathfindingSystem` — система пошуку шляхів з A* алгоритмом
- `SelectionLogic` — логіка вибору об'єктів та пошуку взаємодій
- `SaveManager` — централізований менеджер збереження/завантаження

### [Основні інтерфейси](./core-interfaces.md)
- `IBonusSystem` — інтерфейс системи бонусів та модифікаторів
- `IBuildingsManager` — інтерфейс управління будівлями
- `IDroneManager` — інтерфейс управління дронами
- `IResourceManager` — інтерфейс управління ресурсами
- `IUpgradesManager` — інтерфейс управління апгрейдами
- `ISceneLogic` — інтерфейс логіки 3D сцени
- `IMapLogic` — інтерфейс логіки карти
- `IRequirementsSystem` — інтерфейс системи вимог
- `ISaveManager` — інтерфейс системи збереження/завантаження
- `ICommandGroupSystem` — інтерфейс системи груп команд

## Структура документації

Документація інтерфейсів організована за логічними групами:
- **Модулі** — інтерфейси для бізнес-логіки доменних об'єктів
- **Системи** — інтерфейси для системної інфраструктури
- **Команди** — інтерфейси для системи команд
- **Додаткові системи** — інтерфейси для спеціалізованих систем

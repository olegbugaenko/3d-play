# Структура проекту

Цей розділ містить документацію структури проекту, розділену на логічні частини для кращого розуміння архітектури.

## Логіка системи (Logic)
**Розташування:** `src/logic/`
**Призначення:** Вся бізнес-логіка, модулі та системна інфраструктура проекту.

### [Логіка системи](./logic/index.md)
- **Модулі** — бізнес-логіка доменних об'єктів (BuildingsManager, DroneManager, ResourceManager, UpgradesManager)
- **Системи** — системна логіка та інфраструктура (CommandSystem, MapLogic, BonusSystem, SceneLogic, тощо)

## UI система (User Interface)
**Розташування:** `src/ui/`
**Призначення:** Всі компоненти користувацького інтерфейсу та екрани додатку.

### [UI система](./ui/index.md)
- **Екрани** — основні екрани додатку (Colony Screen, Main Menu)
- **Спільні компоненти** — перевикористовувані UI компоненти (Button, Modal, Menu, тощо)

## Загальна архітектура

### Розділення відповідальності
- **`src/logic/`** — вся бізнес-логіка та системна інфраструктура
- **`src/ui/`** — користувацький інтерфейс та взаємодія
- **`public/`** — статичні ресурси (моделі, текстури, іконки)
- **`docs/`** — документація проекту

### Принципи архітектури
- **Модульність**: Чітке розділення на модулі та системи
- **Інтерфейси**: Використання інтерфейсів для слабкого зв'язування
- **Типізація**: Повна TypeScript типізація всіх компонентів
- **Документація**: Docs-first підхід до розробки
- **Тестування**: Підтримка тестування через інтерфейси

### Технологічний стек
- **Frontend**: React + TypeScript + Vite
- **3D**: Three.js для рендерингу 3D сцени
- **Стилі**: CSS модулі для ізольованих стилів
- **Архітектура**: Модульна архітектура з чіткими інтерфейсами
- **Документація**: Markdown документація з шаблонами

# Логіка системи

Цей розділ містить документацію всієї бізнес-логіки та системної інфраструктури проекту.

## Модулі (Modules)
**Розташування:** `src/logic/modules/`
**Призначення:** Бізнес-логіка доменних об'єктів гри.

### [Модулі](./modules.md)
- **BuildingsManager** — управління будівлями та їх типами
- **DroneManager** — управління дронами та їх станом
- **ResourceManager** — управління ресурсами гри
- **UpgradesManager** — управління апгрейдами та їх ефектами

### Детальна документація модулів
- [Модуль будівель](./buildings-module.md) — повна документація BuildingsManager
- [Модуль дронів](./drones-module.md) — повна документація DroneManager
- [Модуль ресурсів](./resources-module.md) — повна документація ResourceManager
- [Модуль апгрейдів](./upgrades-module.md) — повна документація UpgradesManager

## Системи (Systems)
**Розташування:** `src/logic/systems/`
**Призначення:** Системна логіка та інфраструктура.

### [Системи](./systems.md)
- **MapLogic** — логіка карти та генерація ресурсів
- **BonusSystem** — система бонусів та модифікаторів
- **RequirementsSystem** — система перевірки вимог
- **SceneLogic** — логіка 3D сцени
- **EnvironmentLogic** — система середовища та атмосферних ефектів
- **SaveLoadManager** — система збереження/завантаження

### [Система команд](./commands-system.md)
**Розташування:** `src/logic/systems/commands/`
**Призначення:** Управління виконанням команд для об'єктів у грі, включаючи черги команд, групи команд та динамічну резолюцію параметрів.

### [Система камери](./camera-system.md)
**Розташування:** `src/logic/systems/camera/`
**Призначення:** Управління камерою та її поведінкою в 3D сцені.

### [Система мапи](./map-system.md)
**Розташування:** `src/logic/systems/map/`
**Призначення:** Генерація та управління ігровою картою, ресурсами та террейном.

### [Система модифікаторів](./modifiers-system.md)
**Розташування:** `src/logic/systems/modifiers-system/`
**Призначення:** Управління бонусами, ефектами та ресурсами з автоматичним оновленням залежностей.

### [Система вимог](./requirements-system.md)
**Розташування:** `src/logic/systems/requirements/`
**Призначення:** Перевірка вимог для різних компонентів гри та їх розблокування.

### [Система збереження/завантаження](./save-load-system.md)
**Розташування:** `src/logic/systems/save-load/`
**Призначення:** Централізоване збереження та завантаження стану всіх систем гри.

### [Система сцени](./scene-system.md)
**Розташування:** `src/logic/systems/scene/`
**Призначення:** Управління 3D сценою, об'єктами, террейном та оптимізацією рендерингу.

## Загальна структура логіки

- `src/logic/modules/` — бізнес-логіка доменних об'єктів
- `src/logic/systems/` — системна логіка та інфраструктура
- `src/logic/interfaces/` — інтерфейси для всіх компонентів
- `src/logic/shared/` — спільні утиліти та типи

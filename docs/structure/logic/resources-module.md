## Модуль ресурсів (ResourceManager)
**Розташування:** `src/logic/modules/resources/`
**Призначення:** Управління ресурсами гри, їх балансами, доходами та витратами.

### Підпапки / Файли
- `ResourceManager.ts` — головний менеджер ресурсів
- `resource-types.ts` — типи для ресурсів та їх стану
- `resources-db.ts` — база даних ресурсів
- `index.ts` — експорт модуля

### Залежності
- Використовує: `@interfaces/index`, `@systems/modifiers-system`, `@systems/requirements`
- Використовується у: Всіх модулях та системах для перевірки ресурсів

### Основні компоненти

#### ResourceManager
Головний менеджер ресурсів:
- **Управління балансами**: Поточні кількості всіх ресурсів
- **Доходи**: Автоматичне додавання ресурсів з часом
- **Витрати**: Віднімання ресурсів при використанні
- **Місткість**: Обмеження максимальних кількостей
- **Історія**: Відстеження всіх змін ресурсів

#### ResourceStatus
Стан конкретного ресурсу:
- **Required**: Необхідна кількість для операції
- **Own**: Поточна кількість у гравця
- **IsAffordable**: Чи достатньо ресурсів
- **Progress**: Прогрес збору (0-1)

#### ResourceCheckResult
Результат перевірки ресурсів:
- **IsAffordable**: Чи задоволені всі вимоги
- **Progress**: Загальний прогрес (0-1)
- **Resources**: Стан кожного ресурсу
- **Missing**: Яких ресурсів бракує
- **Totals**: Загальні суми необхідних та наявних ресурсів

### Типи ресурсів

#### Основні ресурси
- **Energy** — енергія для роботи будівель та дронів
- **Stone** — камінь для будівництва
- **Ore** — руда для виробництва
- **Biomass** — біомаса для енергії

#### Характеристики ресурсів
- **Income**: Автоматичний дохід з часом
- **Cap**: Максимальна кількість що можна зберігати
- **Consumption**: Споживання при використанні
- **Multiplier**: Множники ефективності

### Система доходів

#### Автоматичні доходи
- **Енергетичні станції**: Генерація енергії
- **Дрони**: Збір ресурсів з карти
- **Будівлі**: Виробництво спеціалізованих ресурсів
- **Апгрейди**: Покращення доходів

#### Множники доходів
- **Будівлі**: Різні будівлі надають різні множники
- **Апгрейди**: Технологічні покращення
- **Ефективність**: Загальна ефективність колонії

### Система витрат

#### Будівництво
- **Будівлі**: Вартість будівництва нових будівель
- **Оновлення**: Вартість підвищення рівнів
- **Дрони**: Вартість створення нових дронів

#### Експлуатація
- **Енергія**: Споживання енергії будівлями
- **Обслуговування**: Поточні витрати на утримання
- **Команди**: Витрати на виконання команд

### Історія змін

#### ResourceHistoryEntry
Запис зміни ресурсу:
- **Timestamp**: Час зміни
- **ResourceId**: Тип ресурсу
- **Amount**: Кількість зміни
- **Reason**: Причина зміни
- **Balance**: Баланс після зміни

#### Відстеження
- **Всі зміни**: Логування всіх операцій з ресурсами
- **Причини**: Відстеження причин змін
- **Аналітика**: Можливість аналізу витрат та доходів

### Особливості модуля
- **Інтеграція з BonusSystem**: Доходи та місткість покращуються через бонуси
- **Реальний час**: Автоматичне оновлення доходів з часом
- **Валідація**: Перевірка достатності ресурсів перед операціями
- **Підтримка збереження**: Повне збереження стану всіх ресурсів
- **UI інтеграція**: Відображення ресурсів в панелі інтерфейсу

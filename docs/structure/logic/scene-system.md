## Система сцени (SceneLogic)
**Розташування:** `src/logic/systems/scene/`
**Призначення:** Управління 3D сценою, об'єктами, террейном та оптимізацією рендерингу.

### Підпапки / Файли
- `scene-logic.ts` — головна логіка 3D сцени
- `scene.types.ts` — типи для сцени та об'єктів
- `dynamics-logic.ts` — логіка динамічних об'єктів
- `terrain-manager.ts` — управління террейном
- `path-finding/` — система пошуку шляхів
  - `pathfinding-system.ts` — головна система пошуку шляхів
  - `occupancy-grid.ts` — сітка зайнятості для pathfinding
  - `path-finding.types.ts` — типи для pathfinding
- `selection/` — логіка вибору об'єктів
  - `SelectionLogic.ts` — логіка вибору об'єктів
  - `index.ts` — експорт модуля
- `index.ts` — експорт модуля

### Залежності
- Використовує: `@interfaces/index`, `@utils/vector-math`, `@map/map-config`
- Використовується у: Всіх системах та модулях для роботи з 3D об'єктами

### Основні компоненти

#### SceneLogic
Головна логіка 3D сцени:
- **Управління об'єктами**: Додавання, видалення, оновлення об'єктів
- **Система сітки**: Швидкий пошук об'єктів через GridSystem
- **Dirty flags**: Оптимізація рендерингу через відстеження змін
- **Синхронізація ротації**: Автоматична синхронізація з террейном
- **Система тегів**: Фільтрація об'єктів за тегами

#### TerrainManager
Управління террейном:
- **Детермінований шум**: SeededRandom для відтворюваного террейну
- **fBm (fractal Brownian motion)**: Процедурна генерація рельєфу
- **Кешування**: Кешування результатів шуму для продуктивності
- **Профілі seed**: Різні профілі для варіативності террейну

#### PathfindingSystem
Система пошуку шляхів:
- **A* алгоритм**: Оптимальний пошук шляхів
- **OccupancyGrid**: Сітка зайнятості для перевірки прохідності
- **Docking points**: Пошук точок підходу до статичних об'єктів
- **Безпечні відстані**: Урахування розмірів об'єктів при pathfinding

#### SelectionLogic
Логіка вибору об'єктів:
- **Множинний вибір**: Підтримка вибору кількох об'єктів
- **Пошук взаємодій**: Знаходження об'єктів з якими можна взаємодіяти
- **Фільтрація команд**: Відображення тільки доступних команд

### Структура об'єкта сцени
```typescript
interface TSceneObject<T = any> {
  id: string;                    // Унікальний ідентифікатор
  type: string;                  // Тип об'єкта
  coordinates: Vector3;          // Позиція в світі
  scale: Vector3;                // Масштаб
  rotation: Vector3;              // Обертання (Euler)
  rotation2D?: number;           // 2D обертання для terrainAlign
  obstacleSize: number;          // Розмір перешкоди
  data: T;                       // Дані об'єкта
  tags: string[];                // Теги для фільтрації
  bottomAnchor: number;          // Точка якоря
  terrainAlign: boolean;         // Вирівнювання по террейну
  targetType?: string[];         // Типи цілей для взаємодії
  commandType?: string[];        // Доступні команди
  
  // Dirty flags для оптимізації
  _dirtyFlags?: {
    position?: boolean;
    scale?: boolean;
    rotation?: boolean;
    data?: boolean;
    tags?: boolean;
    visibility?: boolean;
  };
  _lastUpdate?: number;
}
```

### Система оптимізації

#### Dirty Flags
Система відстеження змін для оптимізації рендерингу:
- **Відстеження змін**: Тільки змінені об'єкти передаються рендереру
- **Типи змін**: Позиція, масштаб, обертання, дані, теги, видимість
- **Автоматичне очищення**: Dirty flags очищаються після рендерингу

#### Grid System
Система сітки для швидкого пошуку:
- **Розмір клітинки**: 25x25 метрів для оптимального балансу
- **Швидкий пошук**: O(1) доступ до об'єктів в клітинці
- **Фільтрація**: Ефективний пошук об'єктів в області

### Особливості системи
- **Оптимізація рендерингу**: Dirty flags та сітка для продуктивності
- **Террейн-алігнмент**: Автоматичне вирівнювання об'єктів по террейну
- **Детермінованість**: Відтворювані результати через seeded random
- **Розширюваність**: Легко додавати нові типи об'єктів та поведінки
- **Інтеграція**: Тісна інтеграція з усіма системами гри

## Система збереження/завантаження (SaveLoadManager)
**Розташування:** `src/logic/systems/save-load/`
**Призначення:** Централізоване збереження та завантаження стану всіх систем гри.

### Підпапки / Файли
- `save-manager.ts` — головний менеджер збереження/завантаження
- `save-load.types.ts` — типи для збереження/завантаження
- `index.ts` — експорт модуля

### Залежності
- Використовує: `@interfaces/index`, `@systems/map/map-logic`
- Використовується у: `src/logic/core/game/GameServices.ts`

### Основні компоненти

#### SaveManager
Головний менеджер збереження/завантаження:
- **Реєстрація менеджерів**: Реєструє всі системи що підтримують збереження
- **Управління слотами**: Підтримка 5 слотів збереження
- **Централізоване збереження**: Збирає дані з усіх зареєстрованих менеджерів
- **Порядок завантаження**: Контролює порядок завантаження для правильних залежностей

#### SaveLoadManager Interface
Інтерфейс для всіх систем що підтримують збереження:
```typescript
interface SaveLoadManager {
  save(): any;           // Зберегти стан
  load(data: any): void; // Завантажити стан
  reset(): void;         // Скинути до початкового стану
  beforeInit?(): void;   // Ініціалізація перед початком гри
}
```

### Структура збереження
```typescript
interface GameSave {
  slot: number;                    // Номер слота
  timestamp: number;               // Час збереження
  version: string;                 // Версія гри
  resourceManager: ResourceSaveData;
  mapLogic: MapLogicSaveData;
  commandSystem: CommandSystemSaveData;
  commandGroupSystem: any;
  droneManager: DroneSaveData;
  upgradesManager: UpgradesManagerSaveData;
  buildingsManager: BuildingsManagerSaveData;
}
```

### Слоти збереження
- **5 слотів**: Підтримка до 5 збережень одночасно
- **Автоматичне визначення**: Система автоматично визначає які слоти зайняті
- **Метадані**: Зберігає час збереження та версію гри

### Порядок завантаження
Система контролює порядок завантаження для правильних залежностей:
1. **mapLogic** — основа карти
2. **resourceManager** — ресурси
3. **droneManager** — дрони
4. **upgradesManager** — апгрейди
5. **buildingsManager** — будівлі
6. **commandGroupSystem** — групи команд
7. **commandSystem** — команди

### Особливості системи
- **Централізованість**: Всі системи зберігаються через один менеджер
- **Версійність**: Підтримка різних версій збережень
- **Порядок завантаження**: Контроль залежностей при завантаженні
- **Локальне збереження**: Використання localStorage браузера
- **Валідація**: Перевірка коректності збережених даних
- **Розширюваність**: Легко додавати нові системи до збереження

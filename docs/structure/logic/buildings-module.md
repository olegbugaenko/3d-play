## Модуль будівель (BuildingsManager)
**Розташування:** `src/logic/modules/buildings/`
**Призначення:** Управління будівлями, їх типами, будівництвом та оновленнями.

### Підпапки / Файли
- `BuildingsManager.ts` — головний менеджер будівель
- `buildings.types.ts` — типи для будівель та їх стану
- `buildings-db.ts` — база даних типів будівель
- `index.ts` — експорт модуля

### Залежності
- Використовує: `@interfaces/index`, `@systems/modifiers-system`, `@systems/requirements`, `@systems/scene`
- Використовується у: `src/logic/core/game/GameServices.ts`, UI компонентах будівель

### Основні компоненти

#### BuildingsManager
Головний менеджер будівель:
- **Управління типами**: Реєстрація та отримання типів будівель
- **Управління інстансами**: Створення, оновлення та видалення будівель на карті
- **Будівництво**: Планування та виконання будівництва будівель
- **Оновлення**: Підвищення рівнів існуючих будівель
- **Синхронізація**: Інтеграція з 3D сценою та системою бонусів

#### BuildingTypeData
Дані типу будівлі:
- **ID та метадані**: Унікальний ідентифікатор, назва, опис
- **Вартість**: Формула вартості будівництва
- **Вимоги**: Реквайрменти для розблокування будівлі
- **Бонуси**: Модифікатори що надає будівля
- **UI налаштування**: Модель, масштаб, колір для відображення
- **Обмеження**: Максимальний рівень та кількість

#### BuildingInstance
Стан конкретної будівлі на карті:
- **Ідентифікація**: Унікальний ID та посилання на тип
- **Рівень**: Поточний рівень будівлі
- **Стан будівництва**: Чи побудована будівля
- **Позиція**: Координати на карті
- **Прогрес будівництва**: Відстеження процесу будівництва
- **Ресурси**: Зібрані ресурси для будівництва

### Типи будівель

#### Базові будівлі
- **Склад** — зберігання ресурсів
- **Енергетична станція** — генерація енергії
- **Зарядна станція** — зарядка дронів
- **Космічний корабель** — головна будівля колонії

#### Спеціалізовані будівлі
- **Логістичний центр** — покращення ефективності складів
- **Дослідницький центр** — розблокування нових технологій
- **Виробничий комплекс** — переробка ресурсів

### Процес будівництва

#### Планування
1. **Вибір типу будівлі** — з доступних типів
2. **Перевірка вимог** — реквайрменти та ресурси
3. **Вибір позиції** — на вільному місці карти
4. **Підтвердження** — запуск процесу будівництва

#### Будівництво
1. **Збір ресурсів** — дрони збирають необхідні ресурси
2. **Прогрес будівництва** — відстеження завершення
3. **Активація** — будівля стає функціональною
4. **Синхронізація** — оновлення сцени та бонусів

### Система рівнів

#### Підвищення рівня
- **Вартість**: Зростаюча вартість з кожним рівнем
- **Ефекти**: Покращення характеристик будівлі
- **Обмеження**: Максимальний рівень для кожного типу
- **Бонуси**: Додаткові модифікатори на вищих рівнях

### Особливості модуля
- **Інтеграція з BonusSystem**: Будівлі надають бонуси через систему модифікаторів
- **Синхронізація зі сценою**: Автоматичне оновлення 3D об'єктів
- **Підтримка збереження**: Повне збереження стану будівель
- **Валідація реквайрментів**: Перевірка доступності через RequirementsSystem
- **UI інтеграція**: Підтримка модальних вікон та панелей управління

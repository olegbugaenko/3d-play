## Система вимог (RequirementsSystem)
**Розташування:** `src/logic/systems/requirements/`
**Призначення:** Перевірка вимог для різних компонентів гри та їх розблокування.

### Підпапки / Файли
- `RequirementsSystem.ts` — головний клас системи вимог
- `requirements.types.ts` — типи для вимог та результатів перевірки
- `index.ts` — експорт модуля

### Залежності
- Використовує: `@interfaces/index`, `@core/game/GameContainer`
- Використовується у: Всіх модулях для перевірки доступності

### Основні компоненти

#### RequirementsSystem
Головний клас системи вимог:
- **Перевірка вимог**: Централізована перевірка всіх типів вимог
- **Детальна інформація**: Повертає детальну інформацію про стан кожної вимоги
- **Інтеграція з модулями**: Доступ до всіх менеджерів через GameContainer

### Типи вимог (RequirementScope)

#### upgrade
Перевірка рівня апгрейдів:
- Перевіряє чи розблокований апгрейд
- Перевіряє чи досягнутий необхідний рівень

#### building-type
Перевірка загального рівня будівель типу:
- Сумує рівні всіх будівель даного типу
- Перевіряє чи досягнутий необхідний загальний рівень

#### building-instance
Перевірка конкретної будівлі:
- Перевіряє стан конкретної будівлі за ID
- Перевіряє чи побудована та який рівень

#### resource
Перевірка ресурсів:
- Перевіряє чи розблокований ресурс
- Перевіряє чи досягнутий необхідний рівень ресурсу

#### command-group
Перевірка груп команд:
- Перевіряє чи розблокована група команд
- Перевіряє чи досягнутий необхідний рівень групи

### Структура вимоги
```typescript
interface Requirement {
  scope: RequirementScope;
  id: string;        // ID об'єкта для перевірки
  level: number;    // Необхідний рівень
}
```

### Результат перевірки
```typescript
interface RequirementsCheckResult {
  satisfied: boolean;                    // Чи задоволені всі вимоги
  details: RequirementCheckDetail[];   // Деталі по кожній вимозі
}

interface RequirementCheckDetail {
  requirement: Requirement;    // Оригінальна вимога
  satisfied: boolean;          // Чи задоволена ця вимога
  currentLevel: number;        // Поточний рівень
  requiredLevel: number;      // Необхідний рівень
  message: string;            // Описовне повідомлення
}
```

### Особливості системи
- **Централізована перевірка**: Всі вимоги перевіряються в одному місці
- **Детальна інформація**: Повертає не тільки результат, але й деталі
- **Гнучкість**: Підтримка різних типів вимог через scope
- **Інтеграція**: Легкий доступ до всіх менеджерів через GameContainer
- **Розширюваність**: Легко додавати нові типи вимог

## Модулі
**Розташування:** `src/logic/modules/`
**Призначення:** Бізнес-логіка доменних об'єктів та їх управління. Модулі відповідають за конкретні сутності гри та їх стан.

### Підпапки / Файли

#### buildings/
- `BuildingsManager.ts` — управління будівлями та їх станом
- `buildings.types.ts` — типи для будівель
- `buildings-db.ts` — база даних типів будівель
- `index.ts` — експорт модуля

#### drones/
- `DroneManager.ts` — управління дронами та їх характеристиками
- `drone-db.ts` — база даних типів дронів
- `index.ts` — експорт модуля

#### resources/
- `ResourceManager.ts` — управління ресурсами та їх балансами
- `resource-types.ts` — типи для ресурсів
- `resources-db.ts` — база даних ресурсів
- `index.ts` — експорт модуля

#### upgrades/
- `UpgradesManager.ts` — управління апгрейдами та їх рівнями
- `upgrades.types.ts` — типи для апгрейдів
- `upgrades-db.ts` — база даних апгрейдів
- `README.md` — документація модуля
- `index.ts` — експорт модуля

### Залежності
- Використовує: `@interfaces/index`, `@systems/modifiers-system`, `@systems/requirements`, `@save-load`
- Використовується у: `src/logic/core/game/GameServices.ts`, UI компонентах

### Основні компоненти

#### BuildingsManager
Управління будівлями та їх станом:
- Створення та планування будівель
- Управління рівнями та будівництвом
- Синхронізація з 3D сценою
- Інтеграція з системою бонусів
- Підтримка збереження/завантаження

#### DroneManager
Управління дронами та їх характеристиками:
- Створення та оновлення дронів
- Управління батареєю та інвентарем
- Синхронізація з 3D сценою
- Інтеграція з системою бонусів
- Підтримка збереження/завантаження

#### ResourceManager
Управління ресурсами та їх балансами:
- Управління балансами ресурсів
- Автоматичне оновлення доходів/витрат
- Інтеграція з системою бонусів
- Історія змін ресурсів
- Підтримка збереження/завантаження

#### UpgradesManager
Управління апгрейдами та їх рівнями:
- Розблоковка та підвищення рівнів апгрейдів
- Інтеграція з системою бонусів
- Перевірка реквайрментів
- Підтримка збереження/завантаження

### Особливості модулів
- **Інтеграція з BonusSystem**: Всі модулі інтегруються з системою бонусів для динамічних характеристик
- **Синхронізація зі сценою**: Модулі синхронізують свій стан з 3D сценою через SceneLogic
- **Підтримка збереження**: Всі модулі реалізують SaveLoadManager для збереження стану
- **База даних**: Кожен модуль має свою БД з типами та конфігурацією
- **Валідація реквайрментів**: Модулі перевіряють вимоги через RequirementsSystem

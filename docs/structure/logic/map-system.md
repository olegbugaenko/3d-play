## Система мапи
**Розташування:** `src/logic/systems/map/`
**Призначення:** Генерація та управління ігровою картою, ресурсами та террейном.

### Підпапки / Файли
- `map-logic.ts` — головна логіка карти та генерації ресурсів
- `map-config.ts` — конфігурація розмірів мапи та параметрів генерації
- `map-generation-state.ts` — стан генерації карти та відстеження прогресу
- `map-init.ts` — ініціалізація карти та початкового стану
- `seeded-random.ts` — детермінований генератор випадкових чисел
- `index.ts` — експорт модуля

### Залежності
- Використовує: `@scene/scene-logic`, `@commands/CommandSystem`, `@modules/*`
- Використовується у: `src/logic/core/game/GameServices.ts`, UI компонентах

### Основні компоненти

#### MapLogic
Головна логіка карти та генерації ресурсів:
- **Генерація ресурсів**: Каменюки, болдери, біомаса з кластерним розміщенням
- **Детермінована генерація**: Використання seeded random для відтворюваності
- **Система кластерів**: SpatialHash2D для уникнення перекриття ресурсів
- **Автоматична генерація хмар**: Періодичне створення атмосферних ефектів
- **Управління зібраними ресурсами**: Відстеження зібраних каменюків та біомаси

#### MapConfig
Конфігурація параметрів мапи:
- **Розміри світу**: 600x600x600 метрів
- **Параметри генерації**: Кількість кластерів, ресурсів на кластер, радіуси
- **Налаштування террейну**: Роздільна здатність, висоти, текстури
- **Налаштування шуму**: Масштаб, октави, персистентність для procedural генерації

#### SeededRandom
Детермінований генератор випадкових чисел:
- **Відтворюваність**: Однаковий seed дає однакові результати
- **Високоякісний алгоритм**: Використання Linear Congruential Generator
- **Підтримка різних типів**: Float, int, boolean з діапазонами

#### MapGenerationTracker
Відстеження стану генерації:
- **Прогрес генерації**: Відстеження завершених етапів
- **Валідація**: Перевірка коректності згенерованих даних
- **Відновлення**: Можливість продовжити генерацію з місця зупинки

### Типи ресурсів
- **stone** — камінь для будівництва
- **ore** — руда для виробництва
- **biomass** — біомаса для енергії

### Особливості системи
- **Кластерне розміщення**: Ресурси групуються в кластери для реалістичності
- **Мінімальні відстані**: Уникнення перекриття між різними ресурсами
- **Детермінованість**: Однаковий seed завжди дає однакову карту
- **Оптимізація**: SpatialHash2D для швидкого пошуку колізій
- **Атмосферні ефекти**: Автоматична генерація хмар та диму
- **Інтеграція з командами**: Підтримка команд збору ресурсів

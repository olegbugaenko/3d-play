## Система модифікаторів (BonusSystem)
**Розташування:** `src/logic/systems/modifiers-system/`
**Призначення:** Управління бонусами, ефектами та ресурсами з автоматичним оновленням залежностей.

### Підпапки / Файли
- `BonusSystem.ts` — головний клас системи бонусів
- `BonusRegistry.ts` — реєстр джерел бонусів та ефектів
- `DependencyGraph.ts` — граф залежностей між бонусами
- `FormulaEngine.ts` — движок формул для розрахунків
- `bonus-system.types.ts` — типи для системи бонусів
- `README.md` — детальна документація системи
- `index.ts` — експорт модуля

### Залежності
- Використовує: `@interfaces/index`, `@shared/types`
- Використовується у: Всіх модулях (BuildingsManager, UpgradesManager, ResourceManager)

### Основні компоненти

#### BonusSystem
Головний клас системи бонусів:
- **Реєстрація джерел**: Будівлі, апгрейди як джерела бонусів
- **Управління станом**: Рівні та ефективність джерел бонусів
- **Кешування**: Оптимізація продуктивності через кеш результатів
- **Автоматичне оновлення**: При зміні одного бонусу оновлюються всі залежні

#### BonusRegistry
Реєстр джерел бонусів та ефектів:
- **Реєстрація джерел**: Будівлі, апгрейди з їх модифікаторами
- **Реєстрація ефектів**: Глобальні ефекти з початковими значеннями
- **Валідація**: Перевірка коректності реєстрації

#### DependencyGraph
Граф залежностей між бонусами:
- **Побудова графу**: Автоматичне визначення залежностей між бонусами
- **Перевірка циклічності**: Виявлення циклічних залежностей
- **Топологічне сортування**: Визначення порядку оновлення бонусів

#### FormulaEngine
Движок формул для розрахунків:
- **Лінійні формули**: `A * level * efficiency + B`
- **Експоненціальні формули**: `A * (level * efficiency)^B`
- **Кешування результатів**: Оптимізація повторних розрахунків

### Типи формул

#### Linear Formula
```typescript
formula: (data) => ({
  type: 'linear',
  A: 50,  // Множник
  B: 0    // Базове значення
})
```

#### Exponential Formula
```typescript
formula: (data) => ({
  type: 'exponential',
  A: 1,   // Множник
  B: 1.5  // Показник степеня
})
```

### Логіка розрахунку

#### Ресурси
- **income**: Додається (`+=`)
- **multiplier**: Множиться (`*=`)
- **cap**: Додається (`+=`)
- **capMultiplier**: Множиться (`*=`)
- **consumption**: Додається (`+=`)

#### Ефекти
- **income**: Додається (`+=`)
- **multiplier**: Множиться (`*=`)

**Фінальна формула для ефектів:**
```
finalValue = (сума income) * (сума multiplier)
```

### Особливості системи
- **Автоматичне оновлення**: При зміні одного бонусу оновлюються всі залежні
- **Кешування**: Результати формул кешуються для продуктивності
- **Валідація**: Перевірка циклічних залежностей при ініціалізації
- **Гнучкість**: Підтримка різних типів формул та залежностей
- **Інтеграція**: Легка інтеграція з будь-якими модулями через інтерфейси

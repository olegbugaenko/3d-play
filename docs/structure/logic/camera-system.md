## Система камери
**Розташування:** `src/logic/systems/camera/`
**Призначення:** Управління камерою та її поведінкою в 3D сцені.

### Підпапки / Файли
- Система камери поки що не реалізована повністю
- Планується інтеграція з Three.js камерою
- Буде включати управління позицією, обертанням та зумом

### Залежності
- Використовує: `@shared/types/camera.types`
- Використовується у: UI компонентах для управління камерою

### Особливості системи
- **Управління камерою**: Позиція, обертання, зум
- **Інтеграція з UI**: Реагування на події миші та клавіатури
- **Обмеження руху**: Межі руху камери в межах ігрового світу
- **Плавні переходи**: Анімації при зміні позиції камери

### Статус розробки
Система камери знаходиться в стані планування та буде реалізована в майбутніх версіях.

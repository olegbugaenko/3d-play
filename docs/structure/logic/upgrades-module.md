## Модуль апгрейдів (UpgradesManager)
**Розташування:** `src/logic/modules/upgrades/`
**Призначення:** Управління апгрейдами, їх розблокуванням та ефектами.

### Підпапки / Файли
- `UpgradesManager.ts` — головний менеджер апгрейдів
- `upgrades.types.ts` — типи для апгрейдів та їх стану
- `upgrades-db.ts` — база даних апгрейдів
- `README.md` — документація модуля
- `index.ts` — експорт модуля

### Залежності
- Використовує: `@interfaces/index`, `@systems/modifiers-system`, `@systems/requirements`, `@resources/resource-types`
- Використовується у: `src/logic/core/game/GameServices.ts`, UI компонентах апгрейдів

### Основні компоненти

#### UpgradesManager
Головний менеджер апгрейдів:
- **Управління типами**: Реєстрація та отримання типів апгрейдів
- **Розблокування**: Перевірка та розблокування нових апгрейдів
- **Підвищення рівнів**: Оновлення існуючих апгрейдів
- **Ефекти**: Застосування бонусів через систему модифікаторів
- **Вимоги**: Перевірка реквайрментів для розблокування

#### UpgradeTypeData
Дані типу апгрейду:
- **Метадані**: ID, назва, опис
- **Рівні**: Максимальний рівень апгрейду
- **Модифікатор**: Бонуси що надає апгрейд
- **Вимоги**: Реквайрменти для розблокування
- **Вартість**: Формула вартості підвищення рівня
- **UI налаштування**: Іконка, колір, масштаб

#### UpgradeState
Стан конкретного апгрейду:
- **Level**: Поточний рівень апгрейду
- **Unlocked**: Чи розблокований апгрейд

### Типи апгрейдів

#### Технологічні апгрейди
- **Покращена ефективність**: Збільшення продуктивності будівель
- **Розширена місткість**: Збільшення місткості складів
- **Швидкість дронів**: Покращення характеристик дронів
- **Енергетичні системи**: Покращення генерації енергії

#### Логістичні апгрейди
- **Автоматизація**: Автоматичні процеси збору та розвантаження
- **Оптимізація маршрутів**: Покращення pathfinding дронів
- **Координація**: Покращена координація між дронами
- **Резервування**: Системи резервного копіювання

#### Дослідницькі апгрейди
- **Нові технології**: Розблокування нових типів будівель
- **Покращені матеріали**: Нові типи ресурсів
- **Спеціалізація**: Спеціалізовані дрони та будівлі
- **Експериментальні системи**: Передові технології

### Система розблокування

#### Реквайрменти
- **Будівлі**: Необхідні будівлі та їх рівні
- **Ресурси**: Необхідні ресурси для розблокування
- **Апгрейди**: Залежності від інших апгрейдів
- **Час**: Деякі апгрейди розблоковуються з часом

#### Процес розблокування
1. **Перевірка вимог**: Валідація всіх реквайрментів
2. **Сплата ресурсів**: Віднімання необхідних ресурсів
3. **Активація**: Апгрейд стає доступним
4. **Застосування ефектів**: Бонуси починають діяти

### Система рівнів

#### Підвищення рівня
- **Вартість**: Зростаюча вартість з кожним рівнем
- **Ефекти**: Покращення бонусів на вищих рівнях
- **Обмеження**: Максимальний рівень для кожного типу
- **Складність**: Більш складні реквайрменти на вищих рівнях

#### Формули вартості
- **Лінійна**: Постійне збільшення вартості
- **Експоненціальна**: Експоненціальне зростання вартості
- **Ступенева**: Різні вартості для різних рівнів

### UI інтеграція

#### UpgradeDataUI
Дані для відображення апгрейду:
- **Поточний стан**: Рівень та доступність
- **Вартість**: Ресурси необхідні для підвищення
- **Ефекти**: Список бонусів що надає апгрейд
- **Прогрес**: Прогрес до наступного рівня

#### UpgradeEffectUI
Дані для відображення ефектів:
- **Тип ефекту**: Назва бонусу
- **Значення**: Поточне значення бонусу
- **Формула**: Формула розрахунку значення

### Особливості модуля
- **Інтеграція з BonusSystem**: Апгрейди надають бонуси через систему модифікаторів
- **Валідація реквайрментів**: Перевірка доступності через RequirementsSystem
- **Підтримка збереження**: Повне збереження стану всіх апгрейдів
- **UI інтеграція**: Підтримка модальних вікон та панелей апгрейдів
- **Прогресія**: Система прогресивного розблокування нових можливостей

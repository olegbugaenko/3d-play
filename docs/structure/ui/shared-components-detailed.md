## Shared Components - Детальна структура
**Розташування:** `src/ui/shared/`
**Призначення:** Детальна документація всіх перевикористовуваних UI компонентів.

### Підпапки / Файли

#### Button/
Базова кнопка з підтримкою різних варіантів:
- `Button.tsx` — основний компонент кнопки
- `Button.css` — стилі кнопки з варіантами
- `index.ts` — експорт модуля

**Пропси:**
```typescript
interface ButtonProps {
  children: React.ReactNode;
  onClick?: () => void;
  variant?: 'primary' | 'secondary' | 'danger' | 'success';
  size?: 'small' | 'medium' | 'large';
  disabled?: boolean;
  className?: string;
  type?: 'button' | 'submit' | 'reset';
}
```

**Особливості:**
- **Варіанти**: primary, secondary, danger, success
- **Розміри**: small, medium, large
- **Стан**: enabled, disabled
- **Події**: onClick, onMouseEnter, onMouseLeave
- **Доступність**: ARIA атрибути та клавіатурна навігація

#### IconButton/
Кнопка з іконкою та текстом:
- `IconButton.tsx` — компонент кнопки з іконкою
- `IconButton.css` — стилі кнопки з іконкою
- `IconButton.example.tsx` — приклади використання
- `index.ts` — експорт модуля

**Особливості:**
- **Іконки**: SVG іконки з підтримкою тем
- **Позиція**: іконка зліва, справа, зверху, знизу
- **Розміри**: адаптивні розміри залежно від контенту
- **Анімації**: hover ефекти та переходи

#### Modal/
Модальне вікно з повною функціональністю:
- `Modal.tsx` — основний компонент модального вікна
- `Modal.css` — стилі модального вікна
- `index.ts` — експорт модуля

**Пропси:**
```typescript
interface ModalProps {
  isOpen: boolean;
  onClose: () => void;
  title: string;
  children: React.ReactNode;
  size?: 'small' | 'medium' | 'large';
}
```

**Особливості:**
- **Overlay**: напівпрозорий фон з blur ефектом
- **Позиціонування**: центрування на екрані
- **Закриття**: по кліку на overlay або ESC клавіші
- **Анімації**: плавне з'явлення та зникнення
- **Розміри**: адаптивні розміри залежно від контенту
- **Z-index**: правильне налаштування шарів

#### HorizontalMenu/
Горизонтальне меню з підтримкою навігації:
- `HorizontalMenu.tsx` — компонент горизонтального меню
- `HorizontalMenu.css` — стилі горизонтального меню
- `index.ts` — експорт модуля

**Особливості:**
- **Елементи**: кнопки, посилання, розділювачі
- **Активний стан**: підсвічування поточного елемента
- **Адаптивність**: автоматичне приховування на малих екранах
- **Події**: onClick для кожного елемента
- **Стилізація**: кастомні стилі для кожного елемента

#### VerticalMenu/
Вертикальне меню з підтримкою групування:
- `VerticalMenu.tsx` — компонент вертикального меню
- `VerticalMenu.css` — стилі вертикального меню
- `index.ts` — експорт модуля

**Особливості:**
- **Групи**: логічне групування елементів меню
- **Підменю**: підтримка вкладених меню
- **Іконки**: підтримка іконок для елементів
- **Активний стан**: підсвічування поточного елемента
- **Анімації**: плавні переходи при розкритті/закритті

#### resources/
Компоненти для роботи з ресурсами:

##### ResourceIcon/
Іконка ресурсу з підтримкою різних типів:
- `ResourceIcon.tsx` — компонент іконки ресурсу

**Особливості:**
- **Типи ресурсів**: stone, ore, biomass, energy
- **Розміри**: small, medium, large
- **Кольори**: автоматичні кольори для кожного типу
- **Анімації**: hover ефекти та пульсація
- **SVG**: векторні іконки з підтримкою масштабування

##### ResourceCost/
Відображення вартості ресурсів:
- `ResourceCost.tsx` — компонент вартості ресурсів
- `ResourceCost.css` — стилі вартості ресурсів

**Пропси:**
```typescript
interface ResourceCostProps {
  costCheck: ResourceCheckResult;
  showStatus?: boolean; // Чи показувати статус (доступно/недоступно)
  compact?: boolean; // Компактний режим для маленьких елементів
}
```

**Особливості:**
- **Формат**: іконка + кількість для кожного ресурсу
- **Кольори**: різні кольори для достатності/недостатності
- **Анімації**: плавні переходи при зміні значень
- **Компактність**: адаптивне відображення
- **Статус**: візуальні індикатори доступності

##### EffectsSection/
Секція ефектів для відображення бонусів:
- `EffectsSection.tsx` — компонент секції ефектів
- `EffectsSection.css` — стилі секції ефектів

**Особливості:**
- **Список ефектів**: відображення всіх бонусів
- **Формати**: різні формати для різних типів ефектів
- **Кольори**: кольорове кодування типів ефектів
- **Іконки**: візуальні індикатори для кожного ефекту
- **Анімації**: hover ефекти та підсвічування

### Залежності
- Використовує: `@shared/types`, `@utils/*`, `@logic/modules/resources`
- Використовується у: Всіх екранах та компонентах додатку

### Принципи дизайну

#### Консистентність
- **Кольорова схема**: Єдина палітра кольорів для всіх компонентів
- **Типографіка**: Консистентні шрифти та розміри
- **Відступи**: Єдина система відступів та margins
- **Анімації**: Однакові тривалості та easing функції

#### Доступність
- **ARIA атрибути**: Підтримка скрін-рідерів
- **Клавіатурна навігація**: Tab, Enter, Escape підтримка
- **Контрастність**: Достатній контраст для читабельності
- **Розміри**: Мінімальні розміри для touch інтерфейсів

#### Продуктивність
- **Мемоізація**: React.memo для оптимізації рендерингу
- **Ліниве завантаження**: Завантаження компонентів за потребою
- **CSS оптимізація**: Ефективні CSS селектори
- **Бандлінг**: Оптимізація розміру бандлу

### Особливості архітектури
- **Перевикористовуваність**: Один компонент для багатьох випадків використання
- **Типізація**: Повна TypeScript типізація всіх пропсів
- **Стилізація**: CSS модулі з ізольованими стилями
- **Тестування**: Підтримка unit тестування
- **Документація**: JSDoc коментарі для всіх компонентів
- **Приклади**: Example файли для демонстрації використання

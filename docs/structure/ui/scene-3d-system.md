## Scene3D System - Детальна структура
**Розташування:** `src/ui/screens/colony/scene/Scene3D/`
**Призначення:** Система рендерингу 3D сцени з Three.js та управління об'єктами.

### Підпапки / Файли

#### renderers/
Система рендерерів для різних типів об'єктів:
- `RendererManager.ts` — головний менеджер рендерерів
- `BaseRenderer.ts` — базовий клас для всіх рендерерів
- `TerrainRenderer.ts` — рендерер террейну та ландшафту
- `BuildingRenderer.ts` — рендерер будівель та споруд (включає storage індикацію)
- `RoverRenderer.ts` — рендерер дронів та транспорту
- `RockRenderer.ts` — рендерер каменюків та ресурсів
- `BiomassRenderer.ts` — рендерер біомаси та рослин
- `SelectionRenderer.ts` — рендерер вибору об'єктів
- `CloudRenderer.ts` — рендерер хмар та атмосферних ефектів
- `SmokeRenderer.ts` — рендерер диму та частинок
- `FireRenderer.ts` — рендерер вогню та ефектів
- `ExplosionRenderer.ts` — рендерер вибухів
- `ArcRenderer.ts` — рендерер дуг та ліній
- `CubeRenderer.ts` — рендерер кубів (fallback)
- `SphereRenderer.ts` — рендерер сфер (fallback)
- `ResourceIcons.ts` — іконки ресурсів над об'єктами
- `TextureManager.ts` — менеджер текстур та матеріалів
- `index.ts` — експорт всіх рендерерів

#### Scene3D.tsx
Головний компонент 3D сцени:
- **Three.js Setup**: Ініціалізація сцени, камери, рендерера
- **Освітлення**: Ambient та Directional світло
- **Тіні**: Налаштування shadow mapping
- **Анімаційний цикл**: RequestAnimationFrame для рендерингу
- **Ресайз**: Автоматичне масштабування при зміні розміру вікна

### Залежності
- Використовує: `three`, `@logic/systems/scene`, `@ui/shared/*`
- Використовується у: `src/ui/screens/colony/scene/Scene3D.tsx`

### Основні компоненти

#### RendererManager
Головний менеджер рендерерів:
- **Реєстрація рендерерів**: Додавання нових типів рендерерів
- **Управління об'єктами**: Додавання, видалення, оновлення об'єктів
- **Оптимізація**: Кешування та оптимізація рендерингу
- **Синхронізація**: Синхронізація з SceneLogic
- **Dirty flags**: Відстеження змін для оптимізації

#### BaseRenderer
Базовий клас для всіх рендерерів:
- **Абстрактні методи**: `render()`, `addObject()`, `removeObject()`
- **Утилітні методи**: Створення геометрії, матеріалів, мешів
- **Кешування**: Кешування створених об'єктів
- **Оптимізація**: LOD та frustum culling

#### TerrainRenderer
Рендерер террейну:
- **Heightmap**: Рендеринг висот карти
- **Текстури**: Блендинг текстур залежно від висоти
- **Деталізація**: Різні рівні деталізації
- **Оптимізація**: Chunk-based рендеринг

#### BuildingRenderer
Рендерер будівель:
- **3D моделі**: Завантаження та відображення GLB моделей
- **Fallback геометрія**: Куби якщо немає моделі
- **Анімації**: Анімації будівництва та роботи
- **Ефекти**: Пар, дим, вогонь для різних типів будівель
- **Storage HUD**: Візуальна індикація внутрішніх складів будівель
  - Прогрес-бари з кольоровою індикацією (червоний/помаранчевий/зелений)
  - Показ поточних і максимальних значень ресурсів
  - Billboard поведінка (завжди повернуто до камери)
  - Автоматичне позиціонування над будівлею

#### RoverRenderer
Рендерер дронів:
- **Анімовані моделі**: GLB моделі з анімаціями
- **Рух**: Плавна анімація переміщення
- **Статус**: Візуальні індикатори стану (зарядка, завантаження)
- **Траєкторії**: Відображення маршрутів руху

#### SelectionRenderer
Рендерер вибору об'єктів:
- **Highlighting**: Підсвічування вибраних об'єктів
- **Outline**: Контури навколо об'єктів
- **Множинний вибір**: Підтримка вибору кількох об'єктів
- **Анімації**: Плавні переходи при виборі/скасуванні

#### TextureManager
Менеджер текстур:
- **Завантаження**: Асинхронне завантаження текстур
- **Кешування**: Кешування завантажених текстур
- **Оптимізація**: Компресія та оптимізація текстур
- **Матеріали**: Створення та кешування матеріалів

### Система рендерингу

#### Життєвий цикл об'єкта
1. **Додавання**: Об'єкт додається через SceneLogic
2. **Реєстрація**: RendererManager реєструє об'єкт
3. **Рендеринг**: Відповідний рендерер створює 3D представлення
4. **Оновлення**: Dirty flags відстежують зміни
5. **Синхронізація**: Оновлення позиції, ротації, масштабу
6. **Видалення**: Очищення ресурсів при видаленні

#### Оптимізації
- **Frustum Culling**: Рендеринг тільки видимих об'єктів
- **LOD System**: Різні рівні деталізації залежно від відстані
- **Instancing**: Групування однакових об'єктів
- **Dirty Flags**: Рендеринг тільки змінених об'єктів
- **Texture Atlasing**: Об'єднання текстур для зменшення draw calls

### Особливості системи
- **Модульність**: Кожен тип об'єкта має свій рендерер
- **Розширюваність**: Легко додавати нові типи рендерерів
- **Продуктивність**: Оптимізації для великої кількості об'єктів
- **Гнучкість**: Підтримка різних форматів моделей та текстур
- **Інтеграція**: Тісна інтеграція з SceneLogic та логікою гри

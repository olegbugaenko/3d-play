# UI система

Цей розділ містить документацію всіх компонентів користувацького інтерфейсу проекту.

## Екрани (Screens)
**Розташування:** `src/ui/screens/`
**Призначення:** Основні екрани та сторінки додатку.

### [Екрани](./screens.md)
- **Colony Screen** — головний ігровий екран з колонією
- **Menu Screen** — головне меню та налаштування

### Детальна документація екранів
- [Colony Screen](./colony-screen.md) — повна документація головного ігрового екрану
- [Scene3D System](./scene-3d-system.md) — система рендерингу 3D сцени
- [Interaction System](./interaction-system.md) — система взаємодії з 3D сценою

## Спільні компоненти (Shared Components)
**Розташування:** `src/ui/shared/`
**Призначення:** Перевикористовувані UI компоненти.

### [Спільні компоненти](./shared-components.md)
- **Button** — базова кнопка
- **IconButton** — кнопка з іконкою
- **Modal** — модальне вікно
- **HorizontalMenu** — горизонтальне меню
- **VerticalMenu** — вертикальне меню
- **Resources** — компоненти для відображення ресурсів

### Детальна документація компонентів
- [Shared Components Detailed](./shared-components-detailed.md) — повна документація всіх спільних компонентів

## Загальна структура UI

- `src/ui/screens/` — основні екрани додатку
- `src/ui/shared/` — перевикористовувані компоненти
- `src/ui/index.ts` — експорт всіх UI компонентів
- `public/icons/` — іконки та графічні ресурси
- `public/models/` — 3D моделі для сцени
- `public/textures/` — текстури для матеріалів

## Особливості UI архітектури

### Технологічний стек
- **React компоненти** — функціональні компоненти з хуками
- **TypeScript** — повна типізація всіх компонентів та пропсів
- **CSS модулі** — ізольовані стилі для кожного компонента
- **Three.js** — інтеграція з 3D сценою та рендерингом
- **SVG іконки** — векторні іконки з підтримкою тем

### Архітектурні принципи
- **Модульність** — кожен компонент має чітко визначену відповідальність
- **Перевикористовуваність** — спільні компоненти для всіх екранів
- **Консистентність** — єдина дизайн-система та стилі
- **Продуктивність** — оптимізація рендерингу та пам'яті
- **Доступність** — підтримка ARIA атрибутів та клавіатурної навігації

### Система взаємодії
- **Централізована обробка** — InteractionManager для всіх подій
- **Контекстні дії** — різні дії залежно від режиму взаємодії
- **Валідація** — перевірка можливості виконання дій
- **Фідбек** — візуальний фідбек для користувача

### 3D інтеграція
- **Модульні рендерери** — окремі рендерери для кожного типу об'єктів
- **Оптимізація** — frustum culling, LOD, dirty flags
- **Управління камерою** — плавна навігація по 3D сцені
- **Вибір об'єктів** — drag selection та click selection

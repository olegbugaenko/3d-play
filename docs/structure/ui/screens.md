## Екрани (Screens)
**Розташування:** `src/ui/screens/`
**Призначення:** Основні екрани та сторінки додатку з повною функціональністю.

### Підпапки / Файли

#### colony/
Головний ігровий екран з колонією:
- **buildings/** — управління будівлями
  - `BuildingsModal.tsx` — модальне вікно будівель
  - `BuildingsPanel.tsx` — панель будівель
  - `BuildingsModal.css` — стилі модального вікна
- **scene/** — 3D сцена та взаємодія
  - `Scene3D/` — головний компонент 3D сцени
  - `interaction/` — система взаємодії з об'єктами
  - `hooks/` — React хуки для сцени
  - `renderers/` — рендерери для різних типів об'єктів
  - `ui-handlers/` — обробники UI подій
- **ui-controls/** — елементи управління
  - `CommandPanel/` — панель команд
  - `ResourcesBar/` — панель ресурсів
- **upgrades/** — система апгрейдів
  - `UpgradesModal.tsx` — модальне вікно апгрейдів
  - `UpgradesPanel.tsx` — панель апгрейдів
  - `upgrades.types.ts` — типи для апгрейдів

#### menu/
Головне меню та налаштування:
- `MainMenu/` — головне меню додатку
  - `MainMenu.tsx` — основний компонент меню
  - `MainMenu.css` — стилі меню

### Залежності
- Використовує: `@shared/*`, `@logic/*`, `@interfaces/*`
- Використовується у: `src/App.tsx`, роутингу додатку

### Основні компоненти

#### Colony Screen
Головний ігровий екран:
- **3D сцена**: Відображення ігрового світу через Three.js
- **Управління будівлями**: Створення, оновлення та управління будівлями
- **Система команд**: Відправка команд дронам та іншим об'єктам
- **Панель ресурсів**: Відображення поточних ресурсів
- **Система апгрейдів**: Розблокування та підвищення рівнів
- **Взаємодія**: Вибір об'єктів, переміщення камери, drag selection

#### Main Menu Screen
Головне меню додатку:
- **Навігація**: Перехід між різними екранами
- **Налаштування**: Конфігурація гри
- **Збереження**: Управління слотами збереження
- **Нова гра**: Запуск нової гри

### Особливості екранів
- **React компоненти**: Використання функціональних компонентів з хуками
- **CSS модулі**: Ізольовані стилі для кожного компонента
- **TypeScript**: Повна типізація всіх компонентів
- **3D інтеграція**: Тісна інтеграція з Three.js сценою
- **Станівний менеджмент**: Використання React Context та хуків
- **Оптимізація**: Мемоізація та оптимізація рендерингу

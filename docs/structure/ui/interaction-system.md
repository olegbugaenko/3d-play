### Interaction System (Selection → Interactables → Commands)

Цей документ описує, як працюють інтеракції в Colony Scene UI.

## Вибір юнітів (Selection)
- Логіка у `src/logic/systems/scene/selection/SelectionLogic.ts`.
- Виділені обʼєкти зберігаються у `SelectionLogic.selectedObjects`.
- Метод `findInteractableObjects()` повертає список обʼєктів сцени, з якими можна взаємодіяти, виходячи з команд підтримуваних вибраними юнітами.

## Фільтрація по доступних командах
- `findInteractableObjects()` збирає множину доступних команд у вибраних юнітів (`commandType` масив на обʼєкті сцени юніта).
- Далі викликається `SceneLogic.getVisibleObjects({ filterByCommands })` – сцена повертає тільки ті обʼєкти, що мають відповідний `targetType`.
- Узгодження: якщо в юніта є команда `build`, інтерактивним вважається будь‑який обʼєкт з `targetType`, що містить `'build'`.

## Позначення інтерактивних цілей (targetType)
- Кожен обʼєкт сцени може мати поле `targetType: string[]`.
- Приклад: недобудовані будівлі мають `targetType: ['build']`, тому ПКМ запускає групу команд будівництва.
- НОВЕ: недобудовані/заплановані дороги також отримують `targetType: ['build']`, щоб їх можна було будувати дронами через ПКМ.
  - Це виставляється у `BuildingsManager.addRoadToScene()` залежно від стану дороги (не збудована, є сегменти у стані відмінному від `completed`, або `plannedOnly: true`).

## Обробка ПКМ (SelectionHandler)
- `SelectionHandler.handleRightClick()`:
  - визначає, що під курсором (raycast на список інтерактивних обʼєктів);
  - якщо клік по недобудованій будівлі – стартує `construction` групу команд;
  - якщо клік по недобудованій дорозі – стартує `road-construction` групу команд.

## Дороги – агреговане табло (HUD)
- Відображається через `RoadRenderer`, використовує `UiLogicBridge.getRoadAggregates()`.
- Показує: `Segments built/total` та delivered/required по кожному ресурсу.
- Зʼявляється тільки для доріг з незавершеними сегментами.

## Розширення
- Щоб зробити новий інтерактивний тип:
  - дайте юніту нову команду в `commandType`;
  - на обʼєкт сцени повісьте відповідний `targetType`;
  - додайте групу команд у `command-groups-db.ts` і executor.

## Interaction System - Детальна структура
**Розташування:** `src/ui/screens/colony/scene/interaction/`
**Призначення:** Система взаємодії користувача з 3D сценою та об'єктами.

### Підпапки / Файли

#### InteractionManager.ts
Головний менеджер взаємодії:
- **Централізація**: Централізована обробка всіх UI подій
- **Контекст**: Визначення контексту взаємодії (будівництво, команди, збір)
- **Делегування**: Передача подій до відповідних обробників
- **Стан**: Управління станом взаємодії та режимами

#### InteractionHandler.ts
Базовий клас для обробників взаємодії:
- **Абстрактні методи**: `handleClick()`, `handleRightClick()`, `handleDrag()`
- **Утилітні методи**: Пошук об'єктів, валідація дій
- **Контекст**: Доступ до поточного контексту взаємодії
- **Стан**: Управління внутрішнім станом обробника

#### handlers/
Конкретні обробники взаємодії:

##### BuildingHandler.ts
Обробка будівель:
- **Планування**: Вибір позиції для будівництва
- **Валідація**: Перевірка можливості будівництва
- **Попередній перегляд**: Відображення майбутньої будівлі
- **Підтвердження**: Запуск процесу будівництва
- **Скасування**: Відміна планування будівництва

##### CommandHandler.ts
Обробка команд:
- **Вибір цілі**: Вибір об'єкта для команди
- **Валідація**: Перевірка можливості виконання команди
- **Відправка**: Відправка команди через CommandSystem
- **Фідбек**: Візуальний фідбек про результат команди
- **Групи команд**: Підтримка груп команд

##### GatherHandler.ts
Обробка збору ресурсів:
- **Вибір ресурсу**: Вибір ресурсу для збору
- **Валідація**: Перевірка доступності ресурсу
- **Команда збору**: Відправка команди збору дронам
- **Прогрес**: Відстеження прогресу збору
- **Завершення**: Обробка завершення збору

##### SelectionHandler.ts
Обробка вибору об'єктів:
- **Одиночний вибір**: Вибір одного об'єкта
- **Множинний вибір**: Вибір кількох об'єктів
- **Drag selection**: Вибір об'єктів в прямокутнику
- **Фільтрація**: Вибір тільки певних типів об'єктів
- **Скасування**: Скасування вибору

### Контекст взаємодії

#### InteractionContext.tsx
React контекст для взаємодії:
- **Поточний режим**: Будівництво, команди, збір, вибір
- **Вибрані об'єкти**: Список вибраних об'єктів
- **Ціль**: Поточна ціль взаємодії
- **Стан**: Загальний стан взаємодії

#### Режими взаємодії
- **Selection**: Вибір об'єктів на сцені
- **Building**: Планування та будівництво будівель
- **Command**: Відправка команд вибраним об'єктам
- **Gather**: Збір ресурсів дронами
- **Camera**: Управління камерою

### Хуки взаємодії

#### useInteractionManager.ts
Хук для управління взаємодією:
- **Ініціалізація**: Налаштування обробників взаємодії
- **Події**: Обробка подій миші та клавіатури
- **Стан**: Управління станом взаємодії
- **Контекст**: Передача контексту до обробників

#### useBuildingPreview.ts
Хук для попереднього перегляду будівель:
- **Попередній перегляд**: Відображення майбутньої будівлі
- **Валідація**: Перевірка можливості будівництва
- **Позиціонування**: Слідування за курсором миші
- **Візуальні індикатори**: Показ можливості будівництва

#### useDebugInfo.ts
Хук для debug інформації:
- **Статистика**: Статистика сцени та об'єктів
- **Продуктивність**: Метрики продуктивності рендерингу
- **Стан**: Поточний стан різних систем
- **Логи**: Логування подій взаємодії

### UI обробники

#### ui-handlers/
Обробники UI подій:

##### SelectionHandler.ts
Обробник вибору об'єктів:
- **Click selection**: Вибір по кліку
- **Drag selection**: Вибір перетягуванням
- **Keyboard shortcuts**: Гарячі клавіші для вибору
- **Context menu**: Контекстне меню для вибраних об'єктів

### Особливості системи

#### Події миші
- **Left click**: Основний вибір та взаємодія
- **Right click**: Контекстне меню та команди
- **Middle click**: Управління камерою
- **Scroll**: Зум камери
- **Drag**: Переміщення камери та вибір області

#### Події клавіатури
- **ESC**: Скасування поточної дії
- **Delete**: Видалення вибраних об'єктів
- **Ctrl+A**: Вибір всіх об'єктів
- **Ctrl+D**: Скасування вибору
- **Space**: Пауза/продовження гри

#### Валідація дій
- **Ресурси**: Перевірка достатності ресурсів
- **Вимоги**: Перевірка реквайрментів
- **Позиція**: Валідація позиції для будівництва
- **Доступність**: Перевірка доступності команд

### Інтеграція з логікою
- **SceneLogic**: Синхронізація з 3D сценою
- **CommandSystem**: Відправка команд
- **BuildingsManager**: Управління будівлями
- **ResourceManager**: Перевірка ресурсів
- **RequirementsSystem**: Перевірка вимог

### Особливості архітектури
- **Модульність**: Кожен тип взаємодії має свій обробник
- **Розширюваність**: Легко додавати нові типи взаємодії
- **Контекстність**: Різні дії залежно від контексту
- **Валідація**: Централізована валідація всіх дій
- **Фідбек**: Візуальний фідбек для користувача
- **Продуктивність**: Оптимізація обробки подій

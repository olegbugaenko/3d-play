## Colony Screen - Детальна структура
**Розташування:** `src/ui/screens/colony/`
**Призначення:** Головний ігровий екран з повною функціональністю колонії.

### Підпапки / Файли

#### buildings/
Управління будівлями:
- `BuildingsModal.tsx` — модальне вікно зі списком доступних будівель
- `BuildingsPanel.tsx` — панель управління будівлями
- `BuildingsModal.css` — стилі модального вікна будівель
- `index.ts` — експорт модуля

#### scene/
3D сцена та взаємодія:
- `Scene3D/` — головний компонент 3D сцени
  - `Scene3D.tsx` — основний компонент Three.js сцени
  - `renderers/` — рендерери для різних типів об'єктів
    - `RendererManager.ts` — менеджер рендерерів
    - `TerrainRenderer.ts` — рендерер террейну
    - `BuildingRenderer.ts` — рендерер будівель
    - `RoverRenderer.ts` — рендерер дронів
    - `RockRenderer.ts` — рендерер каменюків
    - `BiomassRenderer.ts` — рендерер біомаси
    - `SelectionRenderer.ts` — рендерер вибору об'єктів
    - `TextureManager.ts` — менеджер текстур
- `interaction/` — система взаємодії
  - `InteractionManager.ts` — головний менеджер взаємодії
  - `InteractionHandler.ts` — базовий обробник взаємодії
  - `handlers/` — конкретні обробники
    - `BuildingHandler.ts` — обробка будівель
    - `CommandHandler.ts` — обробка команд
    - `GatherHandler.ts` — обробка збору ресурсів
    - `SelectionHandler.ts` — обробка вибору
- `hooks/` — React хуки
  - `useInteractionManager.ts` — хук для взаємодії
  - `useBuildingPreview.ts` — хук для попереднього перегляду будівель
  - `useDebugInfo.ts` — хук для debug інформації
- `context/` — React контекст
  - `InteractionContext.tsx` — контекст взаємодії
- `components/` — додаткові компоненти
  - `DebugPanel.tsx` — панель debug інформації
  - `VerticalMenuWithContext.tsx` — вертикальне меню з контекстом
- `CameraController/` — управління камерою
  - `CameraController.ts` — контролер камери
- `AreaSelectionRenderer/` — рендерер вибору області
  - `AreaSelectionRenderer.ts` — рендерер області вибору
- `ui-handlers/` — обробники UI подій
  - `SelectionHandler.ts` — обробник вибору об'єктів
- `DragSelection.tsx` — компонент drag selection

#### ui-controls/
Елементи управління:
- `CommandPanel/` — панель команд
  - `CommandPanel.tsx` — компонент панелі команд
- `ResourcesBar/` — панель ресурсів
  - `ResourcesBar.tsx` — компонент панелі ресурсів
  - `ResourcesBar.css` — стилі панелі ресурсів

#### upgrades/
Система апгрейдів:
- `UpgradesModal.tsx` — модальне вікно апгрейдів
- `UpgradesPanel.tsx` — панель апгрейдів
- `upgrades.types.ts` — типи для апгрейдів
- `UpgradesModal.css` — стилі модального вікна апгрейдів

### Залежності
- Використовує: `@ui/shared/*`, `@logic/*`, `@interfaces/*`, `@utils/*`
- Використовується у: `src/App.tsx`, роутингу додатку

### Основні компоненти

#### Scene3D
Головний компонент 3D сцени:
- **Three.js інтеграція**: Повна інтеграція з Three.js для рендерингу
- **Система рендерерів**: Модульна система рендерерів для різних типів об'єктів
- **Управління камерою**: CameraController для навігації по сцені
- **Взаємодія**: Система обробки подій миші та клавіатури
- **Вибір об'єктів**: Drag selection та click selection
- **Debug панель**: Панель для відладки та моніторингу

#### BuildingsModal
Модальне вікно будівель:
- **Список будівель**: Відображення всіх доступних типів будівель
- **Вартість**: Показ вартості будівництва з ResourceCost
- **Ефекти**: Відображення бонусів через EffectsSection
- **Статус доступності**: Візуальне позначення можливості будівництва
- **Вибір будівлі**: Обробка вибору типу будівлі для планування

#### CommandPanel
Панель команд:
- **Доступні команди**: Відображення команд для вибраних об'єктів
- **Групи команд**: Підтримка груп команд з CommandGroupSystem
- **Контекстне меню**: Різні команди залежно від вибраних об'єктів
- **Валідація**: Перевірка можливості виконання команд

#### ResourcesBar
Панель ресурсів:
- **Поточні ресурси**: Відображення всіх ресурсів колонії
- **Прогрес**: Показ прогресу наповнення складів
- **Іконки**: Візуальні іконки для кожного типу ресурсу
- **Анімації**: Плавні переходи при зміні значень

### Система взаємодії

#### InteractionManager
Головний менеджер взаємодії:
- **Обробка подій**: Централізована обробка всіх UI подій
- **Контекст**: Визначення контексту взаємодії
- **Делегування**: Передача подій до відповідних обробників
- **Стан**: Управління станом взаємодії

#### Handlers
Спеціалізовані обробники:
- **BuildingHandler**: Обробка будівель (планування, будівництво)
- **CommandHandler**: Обробка команд (відправка команд дронам)
- **GatherHandler**: Обробка збору ресурсів
- **SelectionHandler**: Обробка вибору об'єктів

### Особливості архітектури
- **Модульність**: Кожен компонент має чітко визначену відповідальність
- **React хуки**: Використання кастомних хуків для логіки
- **Контекст**: React Context для передачі стану між компонентами
- **TypeScript**: Повна типізація всіх компонентів
- **CSS модулі**: Ізольовані стилі для кожного компонента
- **Three.js інтеграція**: Оптимізована інтеграція з 3D бібліотекою

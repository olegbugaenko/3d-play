# Структура репо
- `public/` - моделі, іконки та публічні ассети
- `src/` - код проекту
    - `src/logic/` — бізнес-логіка, сервіси, модулі, типи та інтерфейси.
    - `src/ui/` — React-компоненти, стилі, утиліти для UI.
- `docs/` — документація:
  - `docs/structure/` — структура проєкту (огляд + підрозділи для logic/ui).
  - `docs/interfaces/` — інтерфейси (розбиті по доменах/модулях), є `index.md`.

# Процес "Docs-first"
- Перед пошуком методів/файлів спершу звіряйся з документацією в `docs/`.
- При будь-яких змінах у коді: **онови відповідні розділи в `docs/structure/` та/або `docs/interfaces/`** тією ж відповіддю (окремим diff-ом).
- Якщо документації бракує — спершу **доповни** її (мінімально), а вже потім рефактор/код.
- При оновленні коду користуйся шаблоном `@docs-structure-template.md` для опису змін у `docs/structure/…`.
- Для нових або змінених типів — користуйся `@docs-interface-template.md`.

# Загальні вказівки щодо коду
- Мінімізуй використання any - старайся працювати з типами/інтерфейсами
- Уникай гігантських файлів - файл повинен бути не більше 1000 рядків
- Максимально слідуй структурі
